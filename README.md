# 🧩 Microservices Monorepo

This repository contains multiple Node.js microservices managed as a monorepo using **Turborepo**.

## 📁 Structure

- `services/auth-service/` – Handles authentication and JWT.
- `services/user-service/` – Manages user profiles and accounts.
- `services/payment-service/` – Handles payment processing.

## 🚀 Commands

| Command | Description |
|----------|-------------|
| `npm run dev` | Run all services in development mode |
| `npm run build` | Build all services |
| `npm run lint` | Lint all services |

## 🧰 Tools
- Node.js
- Turborepo
- Docker (optional)
